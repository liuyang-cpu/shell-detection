# 前景提取说明

## 1. 当前默认方式

当前 `shell_hist_yolo` 在 `smart` 模式下，前景提取不再依赖固定灰度阈值，比如 `gray < 250`。

默认做法是：

1. 在每个 `bbox` 内裁剪出对象区域
2. 对这个裁剪区域做 `Otsu` 自适应阈值分割
3. 把灰度低于等于该阈值的区域作为前景候选
4. 对候选区域做连通域分析
5. 选择主连通区域作为最终前景掩膜
6. 仅使用这个前景掩膜内的像素来计算灰度直方图和统计量

简化理解就是：

- 先自动分出“较暗的目标区域”
- 再从这些区域里挑出最主要的那一块

## 2. 为什么不用 `gray < 250`

固定阈值的主要问题是：

- 容易把 `bbox` 内一些不稳定的暗背景一起算进去
- 对不同图片、不同曝光条件不够稳健
- 阈值本身带有较强人工假设

因此当前默认方式改成了自适应分割，不再把 `250` 作为前景提取依据。

## 3. 主连通区域是什么意思

做完自适应阈值后，`bbox` 内可能出现多块暗区域：

- 真正的贝壳主体
- 边缘阴影
- 零散暗噪声
- 背景中的小暗块

代码会把这些暗区域拆成多个连通块，然后优先选择面积更大、位置更接近 `bbox` 中心的那一块，作为最终前景。

这样做的目的，是尽量保留主体对象，减少把零散背景误认为前景的概率。

## 4. 提取后的数据如何使用

前景掩膜不会单独保存成训练标签，但会直接影响下面这些统计：

- 灰度直方图
- `mean`
- `iqr`
- `p10`
- `p90`
- `foreground_ratio`

也就是说，后续写入多通道张量的直方图通道，本质上是在描述“这个前景掩膜里的灰度分布”。

## 5. 两种模式

### `smart`

当前默认模式。

特点：

- 不依赖固定灰度阈值
- 使用 `Otsu + 主连通域`
- 更适合背景不稳定的情况

### `threshold`

兼容旧逻辑的保留模式。

特点：

- 直接使用 `gray < background_threshold`
- 逻辑简单
- 但更容易把暗背景一起纳入前景

## 6. 当前限制

这套方法仍然是启发式的，不是严格语义分割，因此仍然可能受下面因素影响：

- `bbox` 标注过大
- 对象和背景灰度非常接近
- 背景中存在与对象相连的大片暗区域
- 对象本身被切到 `bbox` 边缘，导致主连通域选择变难

如果后续发现误分仍然明显，可以继续增强为：

- 形态学清理
- 多区域合并规则
- 边界先验约束
- 基于样本统计的专用分割策略
